How it works

Privacy

Stored only in this browser

No account, no bank linking, no income information, and no server. Clearing Safari website data or switching phones can erase your records unless you have a backup. To use the app across devices, you must export and restore a backup manually.

For reliable iPhone use, host this single HTML page on HTTPS (for example, GitHub Pages), then in Safari choose Share → Add to Home Screen. Keep the same URL; your records belong to that website's browser storage.
